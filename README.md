# Rental Car Management System

A backend application for managing rental car operations, including vehicle management, reservations, and rental services. Built with Java and Spring Boot, following a service-oriented architecture.

## Technologies

- Java
- Spring Boot
- Spring Data JPA
- AWS

## Key Features

- Vehicle and rental management
- Reservation processing
- Backend service architecture
- Database operations using JPA
- AWS integration

## Getting Started

1. Clone the repository.
2. Configure the application properties and database connection.
3. Configure the required AWS credentials and services.
4. Build and run the Spring Boot application.
